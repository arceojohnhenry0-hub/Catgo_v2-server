# 🐱 CatGO

A browser-based location game inspired by the core loop of location-based collecting games — but built around discovering and collecting cats.

## Features

- 📍 Real GPS location using the browser Geolocation API
- 🗺️ Interactive OpenStreetMap map with Leaflet
- 🐈 Cats spawn around the player's real-world position
- 🎯 Catch interaction with a timing ring
- ✨ Separate Mythical Cat gallery for magical generated creatures
- 📷 Separate Real Cats gallery for cats photographed with your camera
- 📖 Full cat gallery / collection
- ⭐ XP, levels, catch streaks and daily bonus
- 🎒 Treat inventory
- 🔥 Streak system
- 🧭 Nearby cat scanner
- 💾 Server-backed player save when deployed with PostgreSQL
- 📱 Mobile-first responsive UI
- 📦 PWA manifest for an app-like Chrome experience
- 🚀 Render-ready with `render.yaml`
- 🧩 No paid map API key required

## Run locally

```bash
npm install
npm start
```

Open http://localhost:3000

For local development without PostgreSQL, the server uses a lightweight in-memory fallback. For persistent production saves, deploy with Render's PostgreSQL database using the included `render.yaml`.

## Deploy to GitHub + Render

1. Create a GitHub repository.
2. Upload all files in this project.
3. In Render, choose **New → Blueprint** and connect the repository.
4. Render reads `render.yaml`, creates the web service and PostgreSQL database.
5. Open the generated `.onrender.com` URL.
6. Allow location access in Chrome.

## Important

This project uses original CatGO names, mechanics and UI. It does not include Pokémon names, copyrighted Pokémon artwork, or Niantic assets.

## Two separate collections

### ✨ Mythical Cats
The original location-based hunt now contains entirely fictional magical creatures such as Ember Lynx, Moonwhisker, Aurora Wisp and Celestial Lion. These are generated by the game and are never mixed with real-cat photographs.

### 📷 Real Cats
The Cat Camera uses your phone's camera (or a photo selected from your device) to create a separate Real Cats gallery. Photos are stored locally in your browser using IndexedDB. This is intentionally a photo collection rather than a mechanic for physically capturing animals.

**Animal-safety rule:** photograph cats from a safe distance and never chase, grab, trap, or disturb an animal for the game.

## Gameplay

Walk around with location permission enabled. Cats are generated near your location. Tap a cat marker, start the catch attempt, and tap the paw when the timing ring is inside the target zone.

The game stores a player ID in the browser and synchronizes the collection with the server.
